# 🥁 Site de Música — React

Interface de loja de instrumentos musicais criada como atividade de desenvolvimento web, com páginas **Início**, **Sobre nós**, **Instrumentos**, **Endereço** e **Contato**.

## Tecnologias

React, React Router, JavaScript, CSS Modules e Vite.

## Executar

```bash
npm install
npm run dev
```

Execute os comandos **nesta pasta**. Para gerar os arquivos de produção, use `npm run build`.

## Estrutura

- `src/App.jsx`: definição das rotas.
- `src/Componentes/`: componentes de conteúdo e navegação.
- `src/Componentes/css/`: estilos das páginas.
- `src/assets/img/`: imagens.

**Objetivo:** praticar uma aplicação React com várias rotas e componentes reutilizáveis. O conteúdo é demonstrativo.
