Coleção de exercícios de programação e construção de interfaces, reunindo práticas de JavaScript, HTML/CSS e páginas desenvolvidas em React.

## 📁 Conteúdo

| Pasta | Conteúdo |
| --- | --- |
| [AtividadesJavaScript](./AtividadesJavaScript) | Exercícios numerados de JavaScript executados em páginas HTML. |
| [Atividade_violao_reactjs](./Atividade_violao_reactjs) | Interface temática de instrumentos e violões em React e Vite. |
| [site_musica](./site_musica) | Site de instrumentos musicais com páginas de início, sobre, instrumentos, endereço e contato. |
| [site_conscientizacao](./site_conscientizacao) | Arquivos de exercício de interface relacionados à conscientização social; esta subpasta não contém uma aplicação Vite completa. |

## ▶️ Executar

Para os projetos React, instale Node.js e npm. Entre na pasta desejada e execute:

```bash
cd site_musica
npm install
npm run dev
```

Para o projeto de violões, substitua `site_musica` por `Atividade_violao_reactjs`. Para os exercícios em `AtividadesJavaScript/`, abra o HTML desejado no navegador.

## 🧠 Aprendizados

Componentização React, CSS Modules, navegação com React Router, lógica de programação em JavaScript e estruturação HTML.
